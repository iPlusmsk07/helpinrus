# Draft PR: усиление безопасности и надёжности 0.9.3

## Что изменено

- закрыто самостоятельное назначение `admin`, `verified` и других доверенных полей;
- ограничены Supabase grants и RLS по операциям и столбцам;
- новый отклик всегда создаётся как `pending`;
- удаление аккаунта больше не блокируется чатами, сообщениями и связанными записями;
- исключено кэширование Supabase/Auth-ответов Service Worker;
- удалено постоянное локальное хранение профиля, заданий и сообщений;
- выход очищает приватное состояние;
- ссылки авторизации проверяются по origin/callback;
- ложные проверки документов, поддержка, жалобы и платежи заменены честными недоступными состояниями;
- внешний Supabase JS закреплён версией и SRI;
- Netlify публикует только 10 разрешённых файлов;
- добавлены защитные заголовки, lockfile, тесты и read-only GitHub Actions;
- добавлены отчёт, план внедрения, карта системы и инструкция по инцидентам.
