Помогай — обновление единого аккаунта

Изменения:
- Вход теперь называется просто «Вход».
- При регистрации больше не нужно выбирать роль.
- Один аккаунт подходит и для заказа помощи, и для предложения услуг.
- В профиле отображается «Помогает и заказывает».
- В меню аватара добавлены «Мои объявления», «Чаты» и «Начать помогать».
- Кнопка «Начать помогать» сразу открывает публикацию услуги.

Загрузка:
1. Загрузите все файлы из этой папки в корень GitHub-репозитория helpinrus.
2. Подтвердите Commit changes в ветку main.
3. Netlify автоматически опубликует обновление.
