ПОМОГАЙ v0.9.3 — ПРОФИЛЬ И ПРОВЕРКА

ЧТО ИЗМЕНЕНО
- Профиль перестроен: белый фон, крупные гранатовые разделы и белые внутренние карточки.
- Убраны дубли «Избранное», «Мои объявления» и «Чаты» со страницы профиля.
- Тарифы, бонусы и продвижение объединены в раздел «Аккаунт».
- Проверка разделена на обязательную проверку личности по паспорту и отдельную проверку профессионального статуса.
- Настройки и поддержка открываются. Выход перенесён внутрь настроек.
- Редактирование профиля: ФИО, дата рождения и город; пустые поля сохранить нельзя.
- ФИО при регистрации запрашивается сразу.
- Экран бонусов упрощён и оформлен в фирменных цветах.
- Исправлено переполнение блока статистики за счёт удаления дублирующих показателей.

КАК ОБНОВИТЬ NETLIFY
1. Загрузите в корень GitHub файлы из корня этой папки с заменой старых.
2. Не загружайте папку www вместо корневых файлов — она нужна для Capacitor.
3. Дождитесь Published в Netlify.
4. Откройте сайт в приватной вкладке Safari.

ВАЖНО
Паспортная и профессиональная проверки пока являются интерфейсным прототипом. Для реальной проверки нужен отдельный KYC-провайдер и безопасное хранилище документов.
Дата рождения сохраняется в метаданных Supabase Auth и локально; для полноценного серверного хранения позже потребуется добавить поле birth_date в таблицу profiles.
