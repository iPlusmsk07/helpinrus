ПОМОГАЙ v0.9.3 — БЕЗОПАСНАЯ СБОРКА

СТАТУС ВЕРСИИ
- Это frontend-прототип с частичной интеграцией Supabase.
- Реальные платежи, KYC, загрузка паспортов, жалобы и поддержка не подключены.
- Интерфейс явно сообщает об этом и не имитирует успешную отправку документов.

ПРОВЕРКА ПЕРЕД ПУБЛИКАЦИЕЙ
1. Установить Node.js 20 или новее.
2. Выполнить установку зависимостей по lock-файлу.
3. Запустить: pnpm test
4. Запустить: pnpm build
5. Проверить, что в www находятся только публичные web-файлы.

NETLIFY
- Настройки находятся в netlify.toml.
- Build command: node scripts/prepare-www.mjs
- Publish directory: www
- SQL, README, package.json и внутренние документы больше не публикуются.
- Production нельзя менять без успешного Deploy Preview и отдельного подтверждения владельца.

SUPABASE
Для нового проекта SQL выполняется в таком порядке:
1. supabase-schema.sql
2. supabase-auth-migration.sql
3. supabase-security-hardening.sql

Для существующего production сначала проверить supabase-security-hardening.sql
в отдельной Supabase-ветке или тестовом проекте. Скрипт не применять вслепую.

ВАЖНО
- В GitHub разрешён только anon/publishable key. Он публичный по конструкции.
- Service role key, токены, пароли базы и резервные коды запрещено хранить в репозитории.
- До подключения KYC нельзя принимать паспортные и профессиональные документы.
- До подключения серверной платёжной логики нельзя считать демо-бонусы деньгами.
